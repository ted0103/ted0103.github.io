## Why It Exists

A portfolio should make a person easier to understand, not bury them under effects. This site gives my technical, leadership, and creative work one coherent home while leaving room for the next project.

## The Approach

The visual system uses translucent material sparingly, with strong typography and deliberate contrast doing most of the work. Project facts come from an approved local content layer and a curated GitHub metadata sync, so new work can be added without redesigning the site.

## What It Prioritizes

The experience stays useful without motion, JavaScript, or live GitHub access. Progressive enhancement adds atmosphere and feedback, while semantic HTML, keyboard navigation, and explicit fallbacks keep the foundation dependable.
